# 桌面体验与全要素快板接入

本次改动仅在本地验证，未发布线上。

## 界面

- 1000px 及以上：常驻侧栏、发现分类三列节目卡、热榜双列卡、底部迷你播放器。
- 桌面播放器：左侧封面与播放控制，右侧独立滚动讲稿。移动端保留点击封面切换讲稿的方式。
- 生成页使用原始动画 `public/assets/kanshan-running.webp`，角色中心跟随进度条末端；进度是阶段估算，首章全部音频就绪才达到 100%。
- 发现、热榜支持顶部下拉刷新。阻尼后的距离达到 64px（原始约 143px）才在松手时刷新；短拉、横滑、取消不刷新；保留桌面刷新按钮。

## 快板模型

- 讲稿阶段：`server/clapper.mjs` 的 `clapperScriptTask`，从知乎回答和引用材料编排问题引入、问题分析、结论总结三章，约束主韵、对句、七至十字句、事实边界和适度表演标记。
- 音频阶段：`clapperAudioRequest` 将人物音色简介、竹板伴奏、章节衔接和完整韵文放入 `text_prompt`。
- 模型 `seed-audio-1.0`，POST `https://openspeech.bytedance.com/api/v3/tts/create`，`X-Api-Key` 保留在后端。
- 参数为 MP3、44100Hz、`speech_rate: -10`、`enable_subtitle: true`；每段最多 360 字，逐章生成并沿用首章进入播放器机制。
- 不使用 TTS 或双人播客接口替代快板。无效讲稿、权限错误、空音频显式报错。
- 成功响应可以不含 `code`；必须具有有效音频。音频保存到本地，不依赖两小时过期的远程 URL。
