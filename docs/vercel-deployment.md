## 本次变更

增加 Node HTTP / WebSocket 入口，排除本地调试栏、日志和凭据。访客身份通过 HttpOnly 签名 Cookie 保持，客户端伪造身份头会被丢弃。页面先建立访客会话，再请求节目上下文，避免并发首次请求导致身份不一致。

音频生成分批续接，保留绝对段落编号，不重置已有音频和播放器。快板每请求一段，其他类型每请求最多四段。

完整节目使用私有 Blob 分块保存和读取。分享内容只包含标题及音频，不公开讲稿上下文或资料。历史、收藏和个人展示设置仍保留原有设备端存储行为；清除浏览器数据会丢失设备身份和本地列表。

## 实测结果

- 97 项自动测试通过；原有 Worker 构建通过。
- 正式首页、会话和状态接口返回 200，热榜返回真实条目。
- 浏览器加载《一杯咖啡，为什么有那么多风味？》，进入播放器后由用户操作开始播放；进度正常推进，分享弹窗关闭后继续播放。

- 匿名读取分享成功，18 段音频，分享数据不包含 context。
