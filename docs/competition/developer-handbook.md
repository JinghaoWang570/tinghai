## 比赛定位与赛道

面向在校学生及毕业不超过 3 年的职场新人，围绕知乎真实社区场景，探索 AI 在知识社区中的实际价值。

### 灵魂匹配局：社区连接与兴趣社交

- 基于兴趣、观点、内容行为的同好匹配
- AI 社交辅助、表达建议与轻量互动体验
- 话题、回答、收藏、关注关系驱动的社区连接
- 数字分身、Agent 互相交流，以及校园/职场知识社交

### 知识炼金场：学习工具与知识生产

- 基于知乎优质内容的学习助手、问答辅导
- 复习卡片、知识清单、思维导图、学习路径生成
- 图文改编、多模态表达、资料整理与观点对照
- 面向校园学习、职业入门与自我提升的 AI 应用

### 跨次元游乐场：AI 游戏与互动叙事

- 盐言故事、社区内容或原创 IP 的互动叙事
- 文字 AVG、多结局、角色扮演、AI NPC 与动态难度
- 围绕刘看山 IP、社区话题或社交关系的轻量游戏

## 参赛与组队

| 项目 | 官方要求 |
| --- | --- |
| 在校生 | 国内外初高中、专本科、硕士、博士在读学生 |
| 毕业群体 | 毕业不超过 3 年的职场新人 |
| 身份材料 | 在校生提供学生证、学信网或录取通知书等；毕业群体提供毕业证或学信网材料 |
| 队伍 | 单人或 1–5 人团队；可跨校、跨专业 |
| 报名流程 | 报名问卷（上传身份证明）→ 添加官方助手 → 加入社群 → 组队 → 提报作品 |
| 作品数量 | 每队限提交 1 个作品，提交时选择一个赛道 |

## 提交物

截止时间为 9 月 15 日 10:00。两项必交、两项选交：

| 材料 | 要求 |
| --- | --- |
| 可运行体验链接（必交） | 评委可直接操作的完整 Demo。网页提供公网链接；有登录功能须提供测试账号。App/插件/桌面端提供安装包或公开链接及环境说明；硬件/线下装置需提供完整操作与环境说明。建议搭配演示视频。 |

## 评分与奖项

### 评分维度

| 维度 | 权重 |
| --- | --- |
| AI 场景价值 | 35% |
| 创新度 | 25% |
| 完成度 | 25% |
| 产品体验与设计感 | 8% |
| 计划书和演示环节 | 7% |

评分重点包括：是否解决真实痛点、能否在知乎生态产生价值、玩法的新颖性、产品可运行性、UI/UX，以及计划书和路演表达。

### 主奖项（总奖金池 ¥120,000）

| 奖项 | 名额 | 奖金 |
| --- | ---: | ---: |
| 一等奖 | 1 支 | ¥30,000 |
| 二等奖 | 2 支 | ¥10,000/支 |
| 三等奖 | 3 支 | ¥5,000/支 |
| 入围奖 | 9 支 | ¥1,000/支 |

另设每个赛道 1 支、¥2,000 的单项奖（社交创新、学习工具、游戏创意），以及 2 支、¥2,000 的社区人气奖。合作高校在单校有效作品达到 25 份时可评校内奖；校内奖可与主奖项、赛道奖叠加。

## 原创、数据与知识产权

- 所有作品须由团队独立创作；禁止搬运、抄袭、外包代做、一稿多投及使用已获奖/公开发布项目。
- 留存 AI 交互记录、设计底稿和开发日志，主办方可核验创作真实性。
- 不得包含违法、低俗、造谣、侵权、恶意营销等内容；不得未经授权使用第三方商标、IP、人像或版权素材。
- 使用知乎社区内容须遵守开放平台规则，严禁批量爬取或滥用用户数据。
- 作品版权归参赛团队；知乎获得永久、非独家、免费的线上展示与赛事宣传授权。
- 盐选小说及刘看山形象仅限比赛期间使用，赛后不可商用；后续落地合作另行沟通。
