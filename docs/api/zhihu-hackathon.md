# 知乎黑客松开放能力

> 来源：[官方开发者手册](https://my.feishu.cn/docx/Mc80dR5XvoPaYDxcTasc04POnjd)，整理日期：2026-09-07。
> 实际鉴权、字段、错误码与可用额度以 [知乎数据开放平台](https://developer.zhihu.com/) 及官方 Hackathon Skill 为准。

## 接入前检查

- 下载并使用官方 Hackathon Skill 查询赛事接口调用方式。
- 不在仓库提交 API Key、Token 或测试账号；本项目使用 `.env` 管理本地密钥。
- 对限额接口做服务端缓存、请求去重和降级处理。
- 严禁批量爬取或滥用知乎站内用户数据。

## 能力清单

| 能力 | 接口/说明 | 官方限制 |
| --- | --- | --- |
| 知乎热榜 | `GET /api/v1/content/hot_list`；支持最近 N 小时，返回热度、问题标题、优质回答摘要和互动数据 | 100 次/用户/天 |
| 知乎故事 | 五个品类故事，包含标题、摘要、作者、标签、导语和正文 | 以官方 Skill 为准 |
| 关注流 | `GET /openapi/feed/following`；关注/粉丝列表为 `GET /openapi/user/following`、`GET /openapi/user/followers` | 以官方 Skill 为准 |
| 知乎搜索 | `GET /api/v1/content/zhihu_search`；返回问答/文章的标题、摘要、作者、发布时间、相关性、权威度与互动数据 | 1,000 次/用户/天 |
| 全网搜索 | `GET /api/v1/content/global_search`；返回网页标题、摘要、作者、发布时间、相关性与权威度 | 1,000 次/用户/天 |
| 知乎知识 | 面向知识内容的理解、呈现和讨论能力 | 以官方 Skill 为准 |
| 直答 Agent | `POST /v1/chat/completions`；基于知乎优质内容生成可信回答 | 100 次/用户/天 |
| 刘看山 IP | 官方素材包 | 仅比赛期间使用，赛后不得商用 |

## 建议实现

1. 为热榜、站内搜索、全网搜索和直答建立缓存层，缓存键包含查询、时间范围和用户维度。
2. 在调用达到阈值前返回缓存或降级内容，并在界面中说明数据更新时间。
3. 仅在用户触发的产品功能中调用接口，不做无关的批量采集。
4. 将每次接口验证记录到本目录，至少包括日期、接口、参数（脱敏）、响应摘要、限额与异常。
