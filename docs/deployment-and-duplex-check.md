# 提交部署与双工排查（2026-09-15）

## 部署选择

当前仅修改本地，未发布线上，也未购买云资源。

- 普通 Cloudflare 托管不能承诺中国大陆各运营商都稳定直连。Cloudflare 官方说明跨境访问存在延迟和可靠性问题；其中国网络需 Enterprise 套餐及独立订阅，并要求有效 ICP 备案或许可。[官方说明](https://developers.cloudflare.com/china-network/)
- 如已有备案域名和大陆云服务器，可把前端与 Node 服务部署到同一 HTTPS 域名。
- 赶提交且暂无备案时，可考虑香港服务器与独立 HTTPS 域名。香港部署不要求大陆 ICP 备案，但仍需用移动、联通、电信的实际网络验证首页、音频、WebSocket 与知乎/火山链路，不能承诺所有地区可用。[阿里云说明](https://help.aliyun.com/en/icp-filing/basic-icp-service/support/for-the-record-process-faq)
- 公网录音需要安全上下文，正式地址必须配 HTTPS；localhost 的 HTTP 例外不适用于公网地址。[MDN](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

## 上线前必要工作

1. 部署前端和后端代理，保留 WebSocket 升级、SSE 流式响应与适当连接超时；只有静态网页不能完成双工。
2. 密钥仅在服务端配置。不能把 LOCAL_DEV、本机调试工具、免登录接口和本地缓存目录原样公开。
3. 把 15 期预置音频迁移到持久存储，并实现正式目录接口；目前 `/__local/catalog`、恢复、分享接口都限本机访问。
4. 配置正式登录、OAuth 回调、用户权限与额度限制；上线访问范围另行确定。
5. 中央日志继续记录模型、输入输出、错误、请求 ID，脱敏密钥；音频记录大小和音量统计，不逐帧写原始音频。
6. 外网验收：两个连续提问、男女声、不同节目、取消与超时、断线、长回答、预置节目与新生成节目。

顶部连接记录仅展示双工。详细 JSONL 与 `.log` 仍保留全部 API 类型，新增实际录音字节数、RMS/峰值、上游请求 ID、返回音频字节数和主动关闭来源。二进制音频分片聚合统计，避免同步写日志拖慢逐帧处理。

## 本地复测工具

- `node diagnostics/duplex-voice-check.mjs`：对照原男声与女声；也可以传入一个音色 ID。调用真实火山服务。
- `node diagnostics/replay-duplex.mjs`：以本地合成的 PCM 测试问句，连续两次调用《宋代城市生活》不同章节的产品双工接口。经过识别、工具检索、音频及最终上下文；零音频会使验证失败。依赖 `.local-cache/duplex-check.pcm` 测试文件及本地目录缓存。
