# 发现首页（本地验证版）

入口以节目发现为主。顶部搜索入口打开原有的知识提问页，继续保留模型、来源范围、知识库设置。首页按兴趣爱好、人文历史、科技、生活、好奇心组织内容；每类三条，分类栏与横滑内容联动。

## 预置节目的播放流程

精选节目先通过知乎检索、知乎直答、讲稿编排和豆包语音播客生成并保存。打开节目仅加载缓存：看山准备动画与进度条 → 完整播放器 → 用户点击播放。加载文案为“正在准备本期声音”，不宣称刚刚重新生成。取消准备不会替换上一个节目。

- 首页排布与加载：`public/discovery-home.js`、`public/discovery-home.css`
- 五个分类及节目元数据：`public/data/discovery.json`
- 批量备音：`node scripts/seed-discovery.mjs`
- 音频、讲稿、来源和上下文：`.local-cache/catalog/`，不提交 Git。
- 本机读取接口：`GET /__local/catalog/{id}`，每次读取签发有效上下文，保留语音插话能力。
- 调用记录：`log/` 中的 JSONL 和 `.log`。

备音使用双人播客，小海 `zh_female_vv_uranus_bigtts` 与刘飞 `zh_male_liufei_uranus_bigtts`。已完成节目复用缓存，讲稿生成完成后存为 draft，后续音频重试不重复检索。命令会报告每一期的 READY 或 FAILED。

## 大家在听

当前显示真实空态。尚无公开节目目录、发布授权和收听事件数据，不将本机缓存、知乎关注关系或精选节目伪装成他人的收听记录。后续接入用户主动公开分享的节目后填充此区域。

## 发布前

此轮仅在本地运行。预置音频不是部署包的一部分；上线前需要把节目缓存迁移至持久化存储，并将读取接口换为正式服务。不能只部署静态元数据，否则 ready 卡片无法获取声音。
